**标题：** [2 更] 做了个拼豆图纸生成器：现在手机电脑可以扫码互传图纸了

**正文：**

上帖：/t/1237xxx（原帖链接发帖时补）

先感谢 @zhouzhouyyi 上次提的反馈——「图纸每个格子没有标注色号」，已经做了，这次一并汇报近两周的更新。

**这次更了什么：**

1. **可打印图纸导出**：带色号标注 + 网格线，直接打印对着拼；已拼的格子可以勾掉，进度自动保存。色号文字颜色会根据豆色深浅自动切换黑/白，浅色豆也能看清。

2. **微信小程序 + 传输码互传（重点）**：手机上用小程序（搜「我要拼豆图纸」）生成的图纸，可以传到电脑继续编辑；电脑上的图纸也能传回手机。两种方式：
   - **传输码**：电脑端显示 5 位码（如 7K3QM），小程序里输码即取，24 小时有效
   - **链接**：复制完整链接发到手机（微信/文件传输助手），粘贴导入

   实现上没引后端账号体系：图纸数据本身 RLE 压缩后塞进 URL fragment 或云端中转（一个只存 24h 的临时表），源图永远不上传。手机编辑 → 电脑精修 → 打印拼豆，这个流程现在是通的。

3. **其他**：导出图片支持加水印（可关）、图纸改名、小程序端补齐了 3D 分层预览和画笔编辑。

**老内容（上帖）：** 照片上传 → 自动量化到真实色板（MARD / COCO / 速塗 / Perler / Hama / Artkal 共 25 块色板 3759 色，按 Lab 色彩空间做 k-means）→ 调色 → 3D 预览 → 模糊搜图 → 导出 PNG/PDF/CSV/单文件 HTML。

地址：https://perler.phtbyte.com/
