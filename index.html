Perler Blueprint is a free, open-source web tool that turns any photo into a perler bead (fuse bead / hama bead) pattern with real color palettes — MARD, COCO, Perler, Hama, Artkal, 3,700+ colors. Auto color quantization, per-cell color codes, 3D board preview, and printable grid sheets. No sign-up, images never leave your device. Source code (MIT) on GitHub; also available as a WeChat Mini Program.
